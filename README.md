## Description

This repository provides final R scripts and results associated with the publication

Curtis, K. Alexandra, John Calambokidis, Jeffrey Moore, Katherina Audley, Paula Cabanilles, Melvin G. Castaneda, Enrique de Luna, Joëlle De Weerdt, Frank Garita-Alpízar, Pamela Martínez-Loustalot, Jose D. Palacios-Alfaro, Betzi Pérez, Ester Quintana-Rizzo, Nicola Ransome, Kristin Rasmussen, Jorge Urbán R., Francisco Villegas-Zurita, Kiirsten Flynn, Jessica L. Huggins, Ted Cheeseman, Jay Barlow, Morgane Lauf, Karen Martien, and Debbie Steel. 2026. Estimates of U.S. West Coast humpback whale stock abundances and trends: Update for 2021–2024. U.S. Department of Commerce, NOAA Technical Memorandum NMFS-SWFSC-741. https://doi.org/10.25923/xxxx-xxxx

Data for this analysis are maintained by Cascadia Research Collective (https://cascadiaresearch.org/), except for effort data, which were provided directly by the investigators and are included in the data directory of this repository. We also provide a minimum dataset for photo-ID spatial capture histories, individual sex information, and trap location, which allows reproduction of the reported results, but requires some modifications to the scripts provided here to remove most pre-processing steps.
